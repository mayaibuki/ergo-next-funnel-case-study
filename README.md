# ERGO NEXT — AI Instant-Quote Funnel (Case Study)

A product design case study by **Jorge Maya** ([mayaibuki.com](https://mayaibuki.com)).

How I took a small-business insurance quote funnel from 16+ steps to 6 by having the
product gather data instead of asking for it, then validating with the user. Designed
and built in Claude Code, on a design system made for AI agents.

**View the deck:** open `index.html`, or visit the live version on GitHub Pages.

Controls: `←` / `→` (or click) to move between slides, `F` for fullscreen.

Built with plain HTML/CSS/JS. Self-contained — fonts and images are included in the repo.
